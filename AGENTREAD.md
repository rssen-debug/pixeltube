# AGENTREAD.md – Developer Manual for the PixelTube Universe

**Read this first.** This document explains exactly how the factory works,
how to upgrade it, and how to add things without breaking the show.
Written for the next agent/dev taking over the project.

- Project: **PixelTube** – a fully procedural, CPU-only pixel-animation
  factory that produces a 16+ mission-comedy series.
- Everything is deterministic from a `--seed`. No assets, no GPU, no
  external media. Every pixel and every audio sample is generated by code.
- Language of the show: **English**. Code comments may mix Swedish.

## 2. The core loop (what happens when you run make_video.py)

1. `story.make_story(seed, story_index, cast)` → returns
   `{title, cast, scenes[{setting,text,action,reaction,props,mystery}], tags, description, tier}`.
2. For every scene: `story.parse_actions(text, cast)` reads the text and
   decides each actor's action. **The script IS the shot list.**
3. `engine.Scene(...)` builds layers (see §5) and renders frames on demand.
4. Voices: `voice.speak(line, species, seed)` → bleep track per scene.
   Scene duration = `max(bleep length, READING time)` – subtitles must be
   readable! (`tts.estimate_dur` ≈ 0.42 s/word.)
5. Audio: looped movement SFX per actor (`_loop_sfx`), point SFX for
   reactions/events, chiptune ducked to 0.38 under voices.
6. Frames upscaled `--scale`× from the 320×180 pixel canvas → MP4 (h264,
   yuv420p, AAC) via imageio-ffmpeg. Output + `.json` meta in `out/`.

Commands you will use daily:

```bash
python3 make_video.py --seed 77 --story 7 --scale 4 --backend none   # demo
python3 batch.py --count 10 --backend none                           # season (tiers ascend with seeds)
python3 make_video.py --llm --idea "a heist on the moon"            # LLM-written episode
python3 preview.py cast                                             # sprite sheet QA
python3 upload_youtube.py out/ep077-*.mp4 --privacy unlisted
```

`--backend none` = gibberish voices. `--silent` = music+SFX only.
`--backend auto` = gTTS narrator (needs network; we rarely use it now).

## 3. The six story laws (DO NOT violate, they are the retention engine)

Applied research from top anime / Spongebob-grade comedy retention:

1. **Cold open** – every episode starts mid-chaos. Consequence first,
   context maybe. Never "meet the characters".
2. **Flaw engine** – the plot is caused by a character's personality flaw
   (`story.FLAWS`: Doris=overconfidence, Rico=greed, Ash=cowardice,
   Puff=snack obsession, …). Luck never causes conflict; characters do.
3. **Running mystery** – the red spiral / "The Watcher" appears as clues
   (scene flag `mystery: true` → silhouette drawn on the horizon by
   `engine._draw_watcher`). Clues are never explained inside the episode.
4. **Escalation** – every template has a `tier` 1-5. `batch.py` maps
   `seed % len(TEMPLATES)`, so consecutive season episodes climb the
   tiers from petty crime (T1) to a shattered moon (T5 finale).
5. **Cliffhanger endings** – last scene = new question or absurd reveal
   ("The TV switched itself on: LOADING SEASON 2…"). No cozy wrap-ups.
6. **Show, don't explain** – punchlines must be an extreme animation
   (fall/shock/flex/fire), not a sentence. Extend overlays, not prose.

## 4. The verb parser (story.parse_actions)

Rules you must respect when writing text:

- **Whole-word matching** – "wound" never triggers "run".
- **Nearest verb to the name alias wins**, max 6 words away.
- **Forward bias on ties** – if a verb is equally close before and after
  the name, the verb AFTER the name wins ("Doris spun" beats "spun Doris").
- **Group words** (`they`, `both`, `together`, `the duo`) apply the first
  verb in the line to every cast member who doesn't have their own verb.
- Multiple sentences per scene are fine; each character takes ONE action.

Current verb lexicon (`story.VERBS`):

- classic: jump/leap/hop · run/rush/sprint/dash/bolt/charge · dance/boogie
  · spin/twirl · hit/punch/smack/bonk/kick · duck/dodge/crouch
  · wave/salute · sleep/snooze/nap/snore · walk/sneak/stroll/creep
- **v6 superpowers**: fire (blasts/roasts/ignites/firebreathes)
  · shock (gasps/yelps/freezes/stunned)
  · fall (trips/faceplants/topples/tumbles/stumbled)
  · flex (flexes/poses/struts/smirks)

When adding verbs: prefer ones that write naturally AFTER a name. Then add
a test sentence proving who-gets-what (see §8).

## 5. Engine anatomy (engine.py)

### Canvas & layers
- Pixel canvas 320×180 (W×H), `GROUND_Y=150`, upscaled at export.
- `Scene.frame(t)` composites in this order – keep new layers at the right
  depth: sky gradient → stars → light rays → celestial (sun/moon/planet)
  → clouds → floaters → bird → hills (parallax ×3.0) → **Watcher** → sea →
  trees (parallax ×9) → weeds → ground (parallax ×16) → swimmers →
  **actors** → hoppers → particles.

### Characters
- Sprites are `_rows()` text art; every letter Maps to a paint in the
  species tint dict. Dino/bunny body = `O`, **ape body = `M`** (historic
  bug: tint missing `M` → invisible ape; never rename letters casually).
- `REGISTRY` = permanent casting: same name → same species+tint+display
  name forever (`doris`=pink dino, `apan`→Rico brown ape, …). Unknown
  names hash to a stable identity via md5. `alias_group()` feeds the parser.
- `ACTOR_GAP=52` px between the ≤3 actors on stage.

### Actions (`Scene._draw_actors`)
Animation math per action, ALL cycles are aligned with the SFX loops in
`make_video._loop_sfx` – if you change a period, change both:

| action | cycle | loop SFX | overlay |
|---|---|---|---|
| run | step 12 fps tilt | steps @0.24 s | – |
| walk | step | steps @0.48 s (quiet) | – |
| jump | 1.15 s | boing + thud @0.95 | – |
| dance | 0.70 s | boing | 🎵 note floats |
| spin | 1.0 s | whoosh | – |
| hit | 0.90 s | bonk | anger vein + POW star |
| duck | 1.6 s | – (thud land w/ jump) | squash |
| sleep | 2.1 s | snore | zzz stream per actor |
| **fire** | 1.3 s | flame | layered fireball from mouth |
| **shock** | 1.2 s | pop+sparkle | !!-bubble + sweat drop |
| **fall** | 1.9 s | thud @0.42 s | dust + orbiting dizzy stars |
| **flex** | 2.6 s | sparkle | blinking star over shoulder |

All coordinates derived from floats MUST be `int()`-wrapped before PIL
(older crash pattern). Sprites are pasted with alpha; rotation uses
`NEAREST` + `expand=True`.

### Props & worlds
- 7 worlds in `SCHEMES` (forest/night/beach/space/snow/underwater/candy).
- 22 props in `PROPS`: keyword-triggered from scene text
  (`props_for_text`) or forced via scene field `props`. Zones: ground /
  sky-static / baked animation (fish, balloons…).
- `NAME_ALIASES` lets English words in text map to any prop.

## 6. Audio anatomy

- All audio: numpy float32 @ 44100 Hz, mixed in `make_video.py`.
- `voice.py`: one square-wave bleep per syllable (word length//3, max 4),
  pitch per species: dino ×0.95, ape ×1.35, bunny ×1.65 of BASE 380 Hz.
  Deterministic per seed → same character sounds identical forever.
  Punctuation inserts pauses; lines end with a falling "piiiu" pip.
- `music.py`: chiptune bed, ducked to 0.38 during speech, 0.9 otherwise.
- `_loop_sfx(act, dur, phase=actor_index*0.31)` builds the movement
  bed per actor. Phase offset keeps actors desynced (feels alive).

## 7. Recipes (how to add things safely)

### 7.1 New action (checklist!)
1. `engine.ACTIONS` += name.
2. Animation branch in `_draw_actors` (+ optional overlay block after paste).
3. `story.VERBS[name] = [whole words...]` (+ maybe GROUP words untouched).
4. `sfx.py`: synthesize sound + register in `make()`.
5. `_loop_sfx`: loop schedule aligned to the animation cycle.
6. Use it in ≥3 scene texts across templates (cast name within 3 words).
7. Run the season test (§8) + render one episode + LOOK at the frames.

### 7.2 New prop
`_rows` art → `PROPS` entry (name: img fn, zone, settings-set, keywords)
→ `NAME_ALIASES` English->key → quick `preview`/frame render. Respect
`settings`: snowman only snow, fish only underwater, ufo only space/night.

### 7.3 New world
Add `SCHEMES` entry (sky gradient, celest, hills, tree painter + colors,
ground layers, dots, particles, clouds) → SETTING in `story.SETTINGS` →
template scene uses it. Render preview frames for QA.

### 7.4 New template (episode)
Follow the six laws §3. Required: cold-open scene 1; flaw-driven conflict;
exactly one `mystery: true` clue scene; cliffhanger final scene; verbs
near names; 5-6 scenes; settings from `SETTINGS`; tier 1-5. Then run §8.

### 7.5 New character
Add to `engine.REGISTRY` (key → species, tint, display) + `story.FLAWS`
(personality that causes plots). Hash fallback means you can also just
USE a new name – but registry-cast names get curated species identity.

### 7.6 LLM missions
`script_llm.PROMPT_TMPL` already enforces laws 1-6. If Qwen output drifts,
tighten the prompt, not the parser. `_coerce` validates settings and
scene count (3-14).

## 8. Test rituals (run these before shipping ANY story/engine change)

```bash
# 1. whole-season coverage: every template ≥3 actions, all actions used
python3 - <<'EOF'
from story import TEMPLATES, parse_actions
all_a = set()
for t in TEMPLATES:
    acts = set()
    for s in t["scenes"]:
        acts.update(a for a in parse_actions(s["text"], t["cast"]).values() if a)
    print(t["title"], sorted(acts))
    assert len(acts) >= 3, t["title"]
    all_a |= acts
need = {"fire","shock","fall","flex","run","duck","dance","jump","hit","sleep","spin"}
assert not (need - all_a)
print("SEASON OK")
EOF

# 2. engine compiles + mystery bakes + voices deterministic
python3 -m py_compile engine.py story.py make_video.py voice.py sfx.py

# 3. render one episode and LOOK at 4+ frames (eyes beat assertions)
python3 make_video.py --seed 77 --story 7 --scale 4 --backend none
```

## 10. Hard-won lessons (don't relearn them)

- Sprite letters not present in the tint dict render TRANSPARENT. That's
  how the ape once became invisible (body letter `M` undocumented).
- "Almost equal distance" ties in the parser need the forward-bias rule or
  characters perform each other's verbs.
- Never let scene length follow bleep length alone – kids+adults need
  reading time: `max(bleep, 0.42 s/word)`.
- Float→PIL without int() crashes randomly mid-render. Always wrap.
- Deterministic seeds are the brand: never use time-based randomness in
  engine/story/audio. Test randomness belongs in test files only.
